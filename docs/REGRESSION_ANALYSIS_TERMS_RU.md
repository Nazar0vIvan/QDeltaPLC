**Модель в регрессионном анализе включает зависимость и предположения о случайной составляющей.** Одна подобранная кривая — её функциональная часть. Такое разграничение прямо дано в [руководстве NIST](https://www.itl.nist.gov/div898/handbook/pmd/section1/pmd12.htm).

Основные термины:

| Термин | Значение |
| --- | --- |
| **Наблюдение** | Один зарегистрированный результат вместе со значениями условий, при которых результат получен. |
| **Выборка** | Совокупность наблюдений, используемых в анализе. |
| **Отклик** | Результат эксперимента, зависимость которого исследуют. В примере — измеренная длина. |
| **Предсказывающая переменная, предиктор** | Переменная, значение которой используют для описания отклика. В примере — температура. |
| **Фактор** | В планируемом эксперименте — предсказывающая переменная, которую варьируют, чтобы исследовать её влияние на отклик. |
| **Уровень фактора** | Конкретное значение или категория фактора, используемые в эксперименте. |
| **Вид модели** | Выбранная форма зависимости: например, постоянная, прямая или квадратичная зависимость. |
| **Параметры модели** | Неизвестные величины, определяющие конкретную зависимость выбранного вида. У прямой — свободный член и коэффициент наклона. |
| **Оценки параметров** | Значения параметров, найденные по выборке. При другой выборке оценки обычно изменятся. |
| **Модельное значение** | Значение отклика, рассчитанное при заданных предикторах и найденных параметрах. |
| **Невязка, остаток** | Наблюдаемое значение отклика минус соответствующее модельное значение. |

Запишем распространённую модель **среднего отклика** при одной количественной предсказывающей переменной:

$$
Y_i=f(x_i;\beta_1,\ldots,\beta_p)+\xi_i,
\qquad
\mathbb E[\xi_i\mid x_i]=0.
$$

Здесь:

- $i=1,\ldots,n$ — номер наблюдения; $n$ — число наблюдений;
- $x_i$ — заданное значение предсказывающей переменной;
- $Y_i$ — случайный отклик; измеренное значение этого отклика обозначим $y_i$;
- $\beta_1,\ldots,\beta_p$ — неизвестные параметры; $p$ — их число;
- $f$ — выбранная функция, описывающая средний отклик;
- $\xi_i$ — случайное отклонение отдельного отклика от этого среднего, в тех же единицах, что и отклик;
- $\mathbb E[\xi_i\mid x_i]=0$ означает, что среднее случайное отклонение при фиксированном $x_i$ равно нулю.

По данным находят оценки параметров, обозначаемые шляпками. Затем рассчитывают модельные значения и невязки:

$$
\hat y_i=f(x_i;\hat\beta_1,\ldots,\hat\beta_p),
\qquad
r_i=y_i-\hat y_i.
$$

**Случайное отклонение $\xi_i$ и вычисленная невязка $r_i$ различаются:** первое определяется относительно неизвестной зависимости с параметрами $\beta_1,\ldots,\beta_p$, второе — относительно зависимости, найденной по выборке. [NIST: определение и анализ невязок](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd44.htm).

Общий порядок работы следующий:

1. **Определяют отклик и предикторы.** Устанавливают, что измеряют и какую зависимость исследуют.
2. **Выбирают вид модели и предположения о разбросе.** Основанием могут служить физические закономерности, условия эксперимента и графики данных.
3. **Оценивают параметры.** Например, метод наименьших квадратов выбирает параметры, при которых наименьшая сумма:
   $$
   \sum_{i=1}^{n}
   \left[y_i-f(x_i;\beta_1,\ldots,\beta_p)\right]^2.
   $$
   Это один из способов оценивания параметров. [NIST: метод наименьших квадратов](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd431.htm).
4. **Проверяют согласие модели с данными.** Исследуют невязки: есть ли зависимость от предикторов или времени, меняется ли разброс, встречаются ли отдельные резко отличающиеся наблюдения. [NIST: проверка модели](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd44.htm).

В вашем примере с расстоянием $L$ **вид зависимости уже выбран: расстояние считается постоянным**.

Если $L$ заранее известно, параметры подбирать не требуется: вычисляют невязки $L_i-L$. Если $L$ неизвестно, его можно оценить по измерениям. Для трёх **условных** значений 9,9; 10,0; 10,1 мм МНК даёт $\hat L=10{,}0$ мм. Три модельных значения равны 10,0 мм, а невязки равны −0,1; 0; +0,1 мм.

**Аппроксимация данных** означает построение приближённой зависимости по выбранному критерию. **Регрессионный анализ** рассматривает такую зависимость в статистической постановке: оценивает параметры, исследует случайный разброс и обоснованность выводов по данным.
