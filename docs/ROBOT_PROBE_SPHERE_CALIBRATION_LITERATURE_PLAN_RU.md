# План анализа статей для теории калибровки центра шарика

Цель плана — получить из статей раздела 1.5 документа `docs/ROBOT_PROBE_SPHERE_CALIBRATION_THEORY_RU.md` (далее «теория») то, что нужно шагам 2–4 теории: модели факторов влияния, методы их определения, их величины и критерии точности, — и записать это в раздел 1 теории. Правила изложения — `docs/DOCUMENT_STYLE_RU.md`, раздел 9.

Сокращения:

- ММК — математическая модель калибровки: уравнения, связывающие измеренные при касаниях величины с искомыми параметрами (разделы 2–9 теории).
- КТК — критерии точности калибровки: величины, которыми оценивается точность найденного положения центра шарика (раздел 10 теории).
- КИМ — координатно-измерительная машина.
- L3 — источник с этим номером в разделе 1.1 теории: диссертация A. Nubiola о калибровке робота ABB IRB 1600.
- TP6 — модель кинематического щупа Renishaw, для которого раздел 1.2 теории приводит пример хода до срабатывания.
- ABB IRB 1600 — модель промышленного робота ABB.
- ISO — Международная организация по стандартизации (International Organization for Standardization); ISO 230-10 — её стандарт на испытания систем ощупывания станков с ЧПУ (числовым программным управлением).
- DOI — цифровой идентификатор объекта (Digital Object Identifier): постоянный идентификатор статьи.
- PDF — формат электронного документа (Portable Document Format).

## 1. Что берётся из статьи

| Что | Для какого шага теории |
| --- | --- |
| модель фактора влияния или калибровки: уравнения, искомые параметры, допущения | шаг 2, ММК: вид систематической части невязок и матрица чувствительности в (7.6.1) |
| метод определения или измерения величины: что измеряют, чем, сколько касаний или поз, при каких условиях | шаг 4 и процедуры документа стратегии |
| значение величины с условиями, при которых оно получено | шаг 4: порядок величины фактора |
| критерий, которым авторы оценивают точность калибровки или измерения | шаг 3, КТК |

Не берутся: определения терминов, кроме нужных, чтобы понять, что означает взятое число; сведения, не относящиеся ни к одной строке этой таблицы.

## 2. Порядок работы с одной статьёй

1. Извлечь текст PDF (`pdftotext`). Формулы, таблицы и подписи рисунков, искажённые при извлечении, сверить по страницам файла.
2. Прочитать статью целиком. Выводы по аннотации не делаются.
3. Заполнить карточку раздела 3.
4. Проверить карточку: у каждого результата указано место в статье, у каждого значения — условия, при которых оно получено, назван класс объектов.

## 3. Карточка статьи

| Поле | Содержание |
| --- | --- |
| источник | год, авторы, название, журнал, том, страницы, DOI, файл в `manuals/Calibration` |
| класс объектов | на каком оборудовании получены результаты: робот, станок, КИМ, тип щупа |
| задача | что авторы определяют или компенсируют |
| модель | уравнения в обозначениях статьи и соответствие обозначениям теории; допущения |
| метод | что измеряют, чем, число касаний или поз, скорость, условия |
| результаты | значение — условия — место в статье (раздел, таблица, рисунок) |
| критерий точности | какой величиной авторы оценивают результат и как её вычисляют |
| ограничения | что авторы не рассматривают или называют ограничением |

## 5. Результат

1. Карточки записываются в раздел 1 теории и заменяют строки раздела 1.5 «не проанализированы».
2. В таблице факторов раздела 10 теории столбец «из источников» ссылается на карточки. Для фактора, по которому ни одна карточка не даёт величины или метода, пишется «нет данных».
3. Факторы с «нет данных» переходят в документ стратегии как величины, которые определяются измерением.
4. После всех карточек в теории выполняются шаги 3 и 4: КТК и оценка степени влияния факторов.

## 6. Условия завершения

- У каждой статьи из раздела 4 есть карточка.
- У каждого значения в карточке есть место в статье и условия, у каждой карточки — класс объектов.
- Каждая ячейка столбца «из источников» в разделе 10 теории ссылается на карточку или содержит «нет данных».
- Ни один вывод не основан на аннотации.
