## Purpose / Big Picture

Пользователь проводит исследование калибровки трёхмерного контактного щупа, закреплённого на
промышленном роботе, по касаниям неподвижной эталонной сферы. Исследование состоит из шести
шагов в строгом порядке: 1) анализ литературы; 2) определение КТК — количественной меры точности
калибровки; 3) определение факторов влияния на КТК, оценка степени их влияния, их взаимосвязей и
ранжирование (главный шаг); 4) построение ММК — математической зависимости КТК от факторов
влияния; 5) процедуры количественного определения отдельных факторов на реальной установке;
6) выбор метода калибровки, который минимизирует КТК. Шаги 1–4 описываются в
`docs/ROBOT_PROBE_SPHERE_CALIBRATION_THEORY_RU.md` (далее «теория»): только абстрактная математика
и данные публикаций, без сведений о реальной установке. Шаги 5–6 — в
`docs/ROBOT_PROBE_SPHERE_CALIBRATION_METHOD_RU.md` (далее «документ метода»): реальная установка.

Этот план выполняет шаг 1. После него в теории есть раздел «Анализ литературы», в котором для
каждого из 32 источников записана карточка: на каком оборудовании получены результаты, какие
модели, методы и критерии точности использованы, какие значения величин получены и при каких
условиях, с местом в источнике. В конце раздела — сводка: какими критериями источники оценивают
точность (вход шага 2), какие величины факторов влияния известны и для какого класса оборудования
(вход шага 3), какие модели факторов есть (вход шага 4), каких данных нет (вход шагов 5–6). Увидеть
результат: открыть теорию в MarkText; раздел 3 содержит 32 карточки и сводку; механические проверки
раздела 0 `docs/DOCUMENT_STYLE_RU.md` не дают неразобранных находок.

  есть символы вне ASCII: «ź» в именах статей Woźniak и кириллица в папке `ISO-ГОСТ`. Он молча

Термины плана. Щуп (контактный щуп касания, touch-trigger probe) — устройство с шариком на
стилусе, которое выдаёт сигнал, когда шарик касается поверхности. Ход до срабатывания (pretravel) —
путь, на который измерительная машина или робот перемещает корпус щупа от касания шарика с
поверхностью до срабатывания щупа. КИМ — координатно-измерительная машина. Кинематический щуп —
щуп, у которого держатель стилуса лежит на трёх опорах и срабатывание регистрируется по разрыву
электрической цепи через опоры. Эталонная сфера — шар известного номинального радиуса, неподвижный
во время калибровки. Центр шарика в системе фланца — искомый результат калибровки. Средние ошибки
робота — ошибки модели робота, которые зависят от углов сочленений и не сводятся к постоянному
смещению основания или фланца (раздел теории «Ошибки робота, которые искажают найденный центр
шарика»). КТК — критерий точности калибровки, количественная мера точности. ММК — математическая
модель калибровки, зависимость КТК от факторов влияния. Фактор влияния — величина или свойство
оборудования либо плана касаний, от которого зависит КТК; у каждого фактора в этом плане есть
идентификатор ФВ1, ФВ2, … (список ниже). Класс объектов — оборудование, на котором источник получил
результат: тип машины (КИМ, станок с ЧПУ, промышленный робот), её модель, тип щупа, длина стилуса.
Карточка — запись результатов одного источника в теории по шаблону из раздела Plan of Work.
Порция — источники одного этапа.

## Concrete Steps

Команды выполняются в Git Bash из корня репозитория (например, `D:\Qt\QtProjects\RoboCrap`).
`W` — временная папка: каталог scratchpad сеанса, если он есть, иначе `$TEMP/robocrap_lit`. Папка
вне репозитория; её содержимое воспроизводимо и может быть удалено в любой момент.

Извлечение текста источника (пример для L7; имя копии — номер источника, только ASCII):

    W="$TEMP/robocrap_lit"; mkdir -p "$W"
    M="/d/Qt/QtProjects/manuals/Calibration"
    cp "$M/[2003] Woźniak. Metrological Feasibilities of CMM Touch Trigger Probes. Part I.pdf" "$W/L07.pdf"
    pdftotext -enc UTF-8 -layout "$W/L07.pdf" "$W/L07.txt"
    tr -cd '\f' < "$W/L07.txt" | wc -c        # число страниц

Ожидаемый результат для L7: 14 страниц. Если страниц 0, путь содержит символы вне ASCII или файл
не скопирован. Для нормативных документов `M` дополняется `/ISO-ГОСТ`. Страницы с формулами и
рисунками читаются по изображению копии `$W/L07.pdf` инструментом чтения PDF с параметром страниц
(не более 20 страниц за вызов).

Этап 0, шаг 2 — перенумерация одним проходом (запускать один раз; повторный запуск сдвинет номера
ещё раз — перед повтором восстановить файл из копии шага 1):

      use utf8;
      sub n{ exists $m{$_[0]} ? $m{$_[0]} : $_[0] }
      s/^(#{2,4} )(\d+)(?=\.)/$1.n($2)/e;
      s/\x5ctag\{(\d+)\./"\x5ctag{".n($1)."."/ge;
      s/\((\d+)\.(\d+(?:\.\d+)?)\)/"(".n($1).".$2)"/ge;
      s/((?:под)?раздел[а-я]*\s+)(\d+)(?=[.\s,;:)–]|$)/$1.n($2)/ge;' "$T"

Без `use utf8` последнее правило не срабатывает (Surprises & Discoveries). Скрипт меняет и номера
разделов внешних источников, записанные словом «раздел» (например, «L3, раздел 7.6»), поэтому такие
места сверяются с копией до правки.

Этап 0, шаг 3 — найти места для ручной проверки:

    grep -nE 'разделы? [0-9]+[–-][0-9]+|раздел[а-я]* [0-9.]+, [0-9]|раздел[а-я]* 1\.|стратеги' "$T"

## Idempotence and Recovery

Извлечение текста повторяемо: временная папка перезаписывается. Скрипт перенумерации не
идемпотентен: перед повторным запуском файл восстанавливается из копии
`$W/theory_before_stage0.md`; если копия потеряна, исходное состояние — `git show
HEAD:docs/ROBOT_PROBE_SPHERE_CALIBRATION_THEORY_RU.md` плюс незакоммиченные правки пользователя, о
которых нужно спросить пользователя. Удалённый файл прежнего плана восстанавливается командой
`git checkout -- docs/ROBOT_PROBE_SPHERE_CALIBRATION_LITERATURE_PLAN_RU.md` (выполнять только по
просьбе пользователя). Карточки независимы: прерванный этап продолжается с первого источника порции
без карточки.
